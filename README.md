# Git-lessen

Lessenserie voor Git te oefenen.

## Welkom

Welkom bij Demo App! Fijn dat je er bent. Deze startapp is een plek om ideeën
uit te proberen en stap voor stap iets moois te bouwen.

## Over deze demo

In deze demo vind je voorbeeldteksten zoals je die vaak in een nieuwe app ziet.
Gebruik ze als startpunt en pas ze aan voor je eigen project.

### Wat kun je doen?

- Ontdek de voorbeeldinhoud.
- Probeer wijzigingen uit.
- Maak de app helemaal van jezelf.

## Aan de slag

Dit is een demo: vervang deze tekst door uitleg die past bij jouw project.
Veel plezier met bouwen!
